The Anti-Flat Difference

Why modern flat web wrappers fail for mission-critical enterprise desktop consoles, and how Classic Aero UI restores clarity and tactile control.

Proportional Comparison: Left shows default AI-generated flat web dashboards (wasted whitespace, washed-out borders). Right shows Classic Aero UI with 1px snapped boundaries and high information density.
📐

The 1px Law

All borders, cell dividers, and headers snap strictly to physical device pixels with SnapsToDevicePixels="True". No blurry double borders or washed-out cards.

🔤

Subpixel ClearType

Fixed hardware subpixel Segoe UI typography via TextFormattingMode="Display" ensures razor-sharp legibility on industrial monitors and 4K displays.

⚡

Zero Dependencies

100% native WPF XAML and C#. Zero NuGet dependency chains, no third-party package conflicts, no Electron overhead, and instant cold startup.

💡

3D Crystal Status LEDs

Spherical glossy status lenses (Emerald OK, Amber Warning, Crimson Fault, Blue Standby) give operators instant peripheral status recognition.

▶️ How to Run & Try the Demo

Test the live enterprise dashboard, shells, analytics, and dialogs on your Windows machine in seconds.

🖱️

Method A: Double-Click Launcher

Simply double-click Launch-Demo.bat in the project folder. It immediately launches the compiled binary or compiles and starts the app automatically.

⌨️

Method B: Command Line (dotnet run)

Open terminal in the project directory and run dotnet run. The .NET 10 SDK builds and displays the studio showroom instantly.

📁

Method C: Install into Your Project

Run the included setup script: powershell -ExecutionPolicy Bypass -File .agents\skills\classic-aero-ui\scripts\install.ps1 to inject styles into your own WPF app.
